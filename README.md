# QR Code Generator

A clean and lightweight web-based QR Code Generator built with Vanilla JavaScript and QRCode.js.

## Features
- **Instant Generation**: Converts any URL or text input into a scannable QR code.
- **Download Support**: Download your generated QR code directly as a PNG image.
- **Responsive Design**: Minimalist and accessible UI suitable for both desktop and mobile.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- [QRCode.js](https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/KiranSinha872/QR-code-generator.git
   ```
2. Open `index.html` in your browser.
